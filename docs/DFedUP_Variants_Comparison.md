# DFedUP 系列算法变体实验结果与深度对比

本文档旨在记录 DFedUP 系列去中心化联邦学习算法的演进历程、核心逻辑差异以及实验结果对比。

## 1. 算法变体全景对比

| 算法变体 | 通信机制 (Comm.) | 聚合对象 (Aggregation) | 本地训练模式 (Local Training) | 核心改进点 (Key Innovation) |
| :--- | :---: | :---: | :---: | :--- |
| **DFedUP (Base)** | **Push-Sum** | 原型 ($S, W$) | 联合训练 (Joint) | **基准方案**：采用正交初始化的原型共识。 |
| **DFedUP1** | **Neighbor Gossip** | 原型 & 样本数 | 联合训练 (Joint) | **PearFL 模式**：弃用 Push-Sum，改为基于邻域样本量的简单加权聚合。 |
| **DFedUP2** | **Push-Sum** | 原型 ($S, W$) | 联合训练 (Joint) | **零初始化**：取消正交初始化先验，改用零初始化原型，全程执行对齐。 |
| **DFedUP3** | **Push-Sum** | 原型 ($S, W$) | **解耦训练 (Decoupled)** | **分阶段优化**：Phase 1 优化分类头，Phase 2 优化特征提取器并对齐原型。 |
| **DFedUP4** | **Push-Sum** | 原型 ($S, W$) | **解耦训练 + 校准** | **原型校准**：在 Phase 1 引入 `loss_ce_proto`，用共识原型显式校准分类器。 |
| **DFedUP5** | **Push-Sum + Gossip** | 原型 + **Extractor 参数** | 联合训练 (Joint) | **双重共识**：在原型共识基础上，增加特征提取器参数的去中心化聚合。 |

## 3. 核心发现与技术洞察

### 3.1 参数聚合的“降维打击” (DFedUP5)
DFedUP5 的性能（86%）显著高于所有仅依赖原型共识的变体。代码层面显示，它在每轮 Gossip 中不仅交换原型，还对特征提取器（Extractor）的权重进行了去中心化聚合。这证明了**在特征空间对齐的基础上，引入模型层面的参数共享能极大地提升模型的基础泛化能力**。

### 3.2 初始化的灵活性 (DFedUP2 vs Base)
DFedUP2 弃用了 Base 版本中的正交初始化，改用零初始化。实验结果显示，让原型完全由本地数据驱动演化（即使初期由于零对齐可能带来微小波动），其最终收敛性能往往略优于强加的人为正交约束。

### 3.3 解耦训练的边际效应 (DFedUP3 & 4)
DFedUP3 和 4 尝试了解耦训练（Decoupled Learning），DFedUP4 更是引入了共识原型对分类器的反向校准。然而，从结果看，这种复杂的本地训练逻辑在去中心化拓扑下并未带来预期的精度增益，反而可能因为局部优化过于频繁而稀释了全局共识的效果。

### 3.4 鲁棒性验证 (DFedUP1)
DFedUP1 证明了 Push-Sum 机制的重要性。在不具备中心服务器进行全局归一化的情况下，简单的邻居加权（Gossip）容易导致权重偏置，从而使精度显著低于基于 Push-Sum 的版本。
